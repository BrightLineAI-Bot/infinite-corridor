Research checked against official sources on 2026-11-09, before this prototype. Base: main d5057d129, release 862. This is source preparation, not a release or visual acceptance receipt.

Two larger reference systems were also checked. The [MIT-licensed Godot AnimationTree](https://docs.godotengine.org/en/stable/tutorials/animation/animation_tree.html) layers and transitions imported clips inside Godot, but supplies no matching sword motion; [Godot license](https://godotengine.org/license/). Epic’s [Gameplay Ability System](https://dev.epicgames.com/documentation/en-us/unreal-engine/gameplay-ability-system-for-unreal-engine) does coordinate ability effects, animation and cancellation, but its Actor Component runtime is tied to Unreal and the [Unreal Engine EULA](https://www.unrealengine.com/eula/unreal). Both provide design references for separating action events from animation. Porting either engine into the current browser game would duplicate that existing boundary and is not warranted for this timing comparison.

Compatibility and overhead conclusions are engineering inferences from these interfaces and the local `wayfarer-rogue-asset-manifest.md`, not measured benchmarks of the rejected libraries. No purchased asset or new service dependency is required.

## Prototype

`sampleCleaverChoreography` now uses a short counter-load followed by fast acceleration into the canonical contact, then a faster decelerating follow-through. At the normal 75 ms contact time the load interval is 31.5 ms. Hand anticipation reaches 6% against the cut; torso counter-twist loads the existing hip/shoulder layer. Blade travel is halfway through at contact exactly as before. The four endpoints remain right hip → left shoulder → right shoulder → left hip → right hip. The imported and native rigs consume the same frame, with the existing reduced-motion body scaling.

This is an authored procedural clip layer on the approved imported rig, not an imported sword clip or adoption of a third-party animation engine. It reuses the existing bounded sampler and frame object; no additional mesh, pose buffer, skin pass or runtime fetch is introduced. The optional saved cue stays in the existing schema and does not gain a field.

The next accepted cut inherits the exact displayed frame, including early follow-through and idle recovery. The pending-contact producer still gates the visual hit and rebases delayed contact; contact timing/damage/reach/cooldowns, four-cut sequencing, 1000 ms reset, interruption, movement and Echo ownership are untouched. No game/controller file changes are needed.

## Evidence and remaining gates

- Focused Node regressions exercise the actual asset without network: 30/60 Hz samples of all four cuts, gait, reduced motion, finite skin/native geometry, bounded actual right-hand grip residual, immutable source arrays, exact entry at eight interruption points, counter-load and accelerated impact. An initial 7.5% anticipation exceeded the grip tolerance at the fourth low cut; reducing it to 6% passed the unchanged tolerance.
- Existing targeted suites cover the accepted canonical hit, delayed contact, pause/save/reload, dodge/tool/spell/jump cancellation, Echo immutability, four-cut sequencing, idle reset and imported/native paths. Final focused run: 71/71 pass across `cleaver-motion-library`, `close-view-melee-contact`, `close-view-hero`, `cleaver-idle-reset`, `cleaver-four-strike-runtime`, `close-view-cleaver-native` and `cleaver-four-presentation`. These tests establish sampled geometry and mechanics, not perceived animation quality.
- `testing/cleaver-motion-preview.mjs` generates a standalone offline HTML replay from actual sampled imported vertices and held-gear triangles. It offers normal-speed and slow playback plus scrubbing. It is an untextured CPU projection diagnostic: no GPU, game camera, lighting, contact target or hardware performance evidence is implied. The generated preview has to be opened and inspected before claiming a visual witness.
- Required coordinator gate: inspect all four cuts at normal speed in a textured hosted preview, stationary and moving, including a quick follow-up, dodge interruption, Echo, inactivity reset, reduced motion and reload. The short fixed 75 ms startup constrains readability; do not increase canonical timing solely for appearance without a separate approved mechanics decision. Physical-phone FPS/thermals remain unmeasured.

No local server, full local suite, push, PR, version bump or publication was performed in this workstream.
