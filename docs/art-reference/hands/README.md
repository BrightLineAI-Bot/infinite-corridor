# Compact hand references

Start with [the hand reference guide](../../hand-reference-guide.md), then open [the contact sheet](contact-sheet.jpg) and selected originals' reference-sized derivatives in `images/`.

This pack contains 17 licensed reference images, not runtime assets. Stable source IDs are preserved; numerical gaps are intentional. Images are at most 1000 pixels per dimension and have been EXIF-oriented, proportionally resized, alpha-flattened onto #f2f0ea, and encoded as JPEG quality 87. No cropping, mirroring or anatomy changes were applied. They are suitable for visual reference, not archival reproduction.

`manifest.json` records each source URL, original download URL, original SHA-256/dimensions/size, local derivative SHA-256/dimensions/size, credit, license, use and caveats. A derivative's hash will intentionally differ from its original's hash. `ATTRIBUTION.txt` provides complete credit and modification notices. See [license texts and notices](licenses/README.md) before reuse. The repository's general license does not replace these third-party image licenses.

The full-resolution corpus was delivered separately in Library; this compact pack is self-contained for routine study. There is no required Library download, online fetch, renderer plugin, installed 3D model, model training or game-code integration to use these local references.
